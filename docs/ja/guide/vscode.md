# VS Code 拡張機能ガイド

`md-tech-pdf` 拡張機能は、VS Code 内でリアルタイムな印刷品質プレビューを表示し、ワンクリックで PDF 出力を行えるツールです。

## 主な機能

- **印刷品質プレビュー**: 用紙サイズ・余白・フォントを忠実に再現したサイド・バイ・サイドのプレビュー画面。
- **双方向スクロール同期**: エディタのスクロールにプレビューが追従し、プレビューのスクロール操作でエディタの該当行が表示されます。
- **高機能スティッキーツールバー**:
  - `Reload`: キャッシュをバイパスして最新状態で再描画。
  - `Sync: ON / OFF`: スクロール同期の有効/無効を切り替え。
  - `Anim: smooth / instant`: スクロールアニメーション（スムーズまたは即時）を切り替え。
  - `Delay: 0ms / 20ms / 50ms / 100ms`: スクロール同期のデバウンス間隔を微調整。
  - `Zoom`: 表示倍率の切り替え（`Fit Width`, `50%`, `75%`, `100%`, `125%`, `150%`）。
  - `Export PDF`: ツールバーから即座に PDF 出力。
- **ダイアグラム永続キャッシュ**: 描画済み SVG をディスクストレージに保存し、VS Code 再起動後も待ち時間なしでプレビューを復元。

## コマンド一覧

| コマンド                        | タイトル                     | 説明                                                          |
| :------------------------------ | :--------------------------- | :------------------------------------------------------------ |
| `md-tech-pdf.openPreview`       | `Open Technical PDF Preview` | アクティブな Markdown ドキュメントのプレビューを開きます。    |
| `md-tech-pdf.exportPdf`         | `Export to PDF`              | 設定された出力先（または同ディレクトリ）へ PDF を出力します。 |
| `md-tech-pdf.exportPdfAs`       | `Export to PDF As...`        | 出力先ファイル名を指定して PDF を出力します。                 |
| `md-tech-pdf.clearDiagramCache` | `Clear Diagram Cache`        | キャッシュされたダイアグラム SVG を安全に全消去します。       |
